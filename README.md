# ShowDeck Pro Desktop

Единый десктопный плеер презентаций и медиафайлов для мероприятий, конференций и сценических площадок. Поддерживает воспроизведение **PDF**, **PPTX**, видеофайлов (**MP4**, **MOV**, **WEBM**, **MKV**), управление USB-кликерами и синхронизированный двухэкранный вывод (**Output**). Все библиотеки (`PDF.js`, `JSZip`, `Tailwind CSS`) и шрифты (`Inter`, `JetBrains Mono`) встроены в сборку для полностью автономной работы без интернета и CDN.

## Основные возможности

- **Автономная работа без CDN:** все зависимости и шрифты упакованы внутрь приложения.
- **Единый плейлист:** добавление PDF-документов, презентаций PPTX, видеороликов и пользовательских шрифтов (`.ttf`, `.otf`) перетаскиванием в окно программы.
- **Сохранение шрифтов:** загруженные файлы шрифтов и шрифты из Google Fonts сохраняются в данных приложения и автоматически загружаются при следующем запуске.
- **Файлы проектов:** сохраняйте плейлист, медиа, исходники PPTX и загруженные шрифты в один файл `.showdeck`, чтобы открыть и продолжить работу позже.
- **Двухэкранный вывод (Output):** отдельное окно вывода для проектора или LED-экрана с синхронизацией переключения слайдов и роликов.
- **Автоскрытие курсора:** курсор мыши автоматически скрывается через **1.2 секунды** бездействия при полноэкранном воспроизведении и снова появляется при движении.
- **Гибкое управление видео и звуком:** настройка поведения видео по кликеру и маршрутизации звука между окнами.
- **Чёткий вывод:** PDF и PPTX рендерятся с разрешением до 3200 px (максимум 8 мегапикселей) и сохраняются в WebP высокого качества, где это поддерживается.

В эфирном окне **Output** видео декодирует встроенный динамически связанный **libVLC**; операторский PGM-просмотр использует Chromium. Output управляется из ShowDeck и поддерживает паузу, перемотку, громкость, повтор и полноэкранный режим. Доступность декодеров зависит от формата и платформы. FFmpeg в установщик не включён.

При воспроизведении из проекта медиафайл временно материализуется в системной временной папке, чтобы libVLC мог открыть его по пути; временная копия удаляется при закрытии Output или приложения. Исходный проект не изменяется. Счётчик **«Кадры»** в операторском PGM относится только к Chromium-превью, а не к декодеру эфирного Output.

Если ролик дёргается, проверьте счётчик кадров и попробуйте перекодировать файл, например в HandBrake: контейнер **MP4**, видеокодек **H.264 (x264)**, частота кадров **Same as source / Constant Framerate**, звук **AAC**. Для показа в Full HD можно ограничить разрешение до **1920×1080**. Высокий битрейт, неподдерживаемый кодек, нагрузка системы или медленный диск также могут вызывать рывки.

## Скачивание и установка

Актуальные установщики для macOS и Windows доступны на странице [**Releases**](https://github.com/biznestver-dev/showdeck-pro/releases/latest).

### macOS (Apple Silicon M1–M4 / Intel)

1. Перейдите в раздел [**Releases**](https://github.com/biznestver-dev/showdeck-pro/releases/latest) и скачайте `.dmg` из блока **Assets**:
   - `ShowDeck.Pro-1.0.6-arm64.dmg` — для Mac на чипах **Apple Silicon (M1, M2, M3, M4)**;
   - `ShowDeck.Pro-1.0.6-x64.dmg` — для Mac на процессорах **Intel**.
2. Откройте скачанный образ `.dmg` и перетащите иконку **ShowDeck Pro** в папку **Программы (Applications)**.
3. **Первый запуск:** поскольку сборка не подписана платным сертификатом Apple Developer ID, macOS при первом открытии может показать предупреждение *«Приложение повреждено, и его не удается открыть»*. Чтобы разрешить запуск, откройте **Терминал** (`Cmd + Пробел` → `Terminal`) и выполните команду:
   ```bash
   xattr -cr "/Applications/ShowDeck Pro.app" && codesign --force --deep --sign - "/Applications/ShowDeck Pro.app"
   ```
4. Запустите **ShowDeck Pro** из папки **Программы (Applications)**.

### Windows

1. Перейдите в раздел [**Releases**](https://github.com/biznestver-dev/showdeck-pro/releases/latest) и скачайте файл `ShowDeck.Pro-Setup-1.0.6-x64.exe` из блока **Assets**.
2. Запустите установщик (если Windows SmartScreen покажет предупреждение о неизвестном издателе, нажмите **Подробнее** → **Выполнить в любом случае**).

## Сборка из исходников (для разработчиков)

Требуется **Node.js 24** или новее.

### Локальный запуск
```sh
npm ci
npm start
```

### Сборка установщиков
```sh
npm run dist:mac
npm run dist:win
```

Сборка установщиков включает VLC 3.0.24 и плагины в `resources/vlc`. Локально задайте `VLC_RUNTIME_DIR` (путь к `Contents/MacOS` на macOS или к папке VLC на Windows); macOS также поддерживает `VLC_APP_PATH`. GitHub Actions загружает официальные runtime-архивы VideoLAN с проверкой SHA-256. Готовые установщики записываются в папку `release/`. Сборка macOS поддерживает архитектуры Intel и Apple Silicon (выполнять на macOS), сборка Windows выполняется на Windows.

Перед публикацией установщика необходимо проверить лицензии всех включённых VLC-плагинов и выполнить соответствующие требования к уведомлениям и исходному коду. См. [THIRD_PARTY_NOTICES.md](./THIRD_PARTY_NOTICES.md).

Установщики не подписаны сертификатом разработчика и не нотарифицированы. При установке macOS Gatekeeper или Windows SmartScreen могут показать предупреждение.
